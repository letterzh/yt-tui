# yt-tui

Ищите видео, добавляйте каналы в подписки и скачивайте ролики. Приложение запускается в терминале; настройки по умолчанию уже готовы.

## Быстрый запуск

Откройте папку проекта и запустите:

- Linux/macOS: `./run.sh`
- Windows: дважды щёлкните `run.bat` или запустите его из терминала.

Скрипт сам создаст `.venv`, установит зависимости и откроет приложение. При первом запуске нужен интернет для установки пакетов.

## Вкладки

- **Рекомендации** — новые ролики из добавленных каналов.
- **Подписки** — локальный список каналов и авторов.
- **Поиск** — поиск на YouTube по названию или поиск видео по прямой ссылке с сайтов, поддерживаемых [yt-dlp](https://github.com/yt-dlp/yt-dlp).
- **Загрузки** — история загрузок и их статус.

Выберите видео стрелками и нажмите `d`, чтобы скачать его.

## Клавиши

- `1`–`4` или `Tab` — переключать вкладки
- `r` — обновить рекомендации
- `s` — открыть поиск
- `d` — скачать выбранное видео
- `x` — удалить выбранную подписку
- `q` — выйти

## Где хранятся файлы

- Скачанные видео — в папке `downloads/`.
- Подписки и история — в базе `videos.sqlite3`.
- Для изменения папки загрузки скопируйте `.env.example` в `.env` и задайте `VIDEO_DOWNLOAD_DIR`.

`ffmpeg` улучшает выбор качества и объединяет отдельные дорожки, если сайт отдаёт видео и звук раздельно.
